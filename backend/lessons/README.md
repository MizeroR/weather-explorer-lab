# Builder Levels

These runnable files follow the same style as earlier Python exercises: read the instructions, complete the referenced TODOs in the real backend file, run the level, and use the checkpoint message to guide your next step.

Run commands from the `backend` directory:

```bash
python3 lessons/level_01_weather_data.py
python3 lessons/level_02_forecast_analysis.py
python3 lessons/level_03_umbrella.py
python3 lessons/level_04_weather_api.py
python3 lessons/level_05_flask_routes.py
python3 lessons/level_06_final_check.py
```

Levels 1-3 work offline. Level 4 needs internet access for Open-Meteo. Levels 5-6 check Flask locally. The required path has 11 TODOs total. Comparison, chart transformation, and quiz features are intentionally outside the core project.
